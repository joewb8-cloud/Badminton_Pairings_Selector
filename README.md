# 🏸 Badminton Player Selector

A free, offline-friendly web app that picks fair doubles games for your badminton club, on **1 or 2 courts**.

**▶ Use it here:** `https://YOUR-USERNAME.github.io/badminton-selector/`

## Features
- **Smart pairings.** Everyone gets to partner everyone else before anyone repeats a partner.
- **Fair court time.** Players who have played the fewest games get picked first.
- **Skill balancing.** Each player has an Elo-style rating that updates after every result, so teams stay even.
- **Varied opponents.** The app avoids putting the same people against each other again and again.
- **1 or 2 courts.** In 2-court mode each court has its own *Next Game* button and nobody gets put on both courts.
- **Saves automatically.** Players, wins and ratings stay in your browser, even after you close it.
- **Works offline and installs like an app** on Android, iPhone, Windows and Mac.

## Install it on your device
| Device | How |
|---|---|
| Android (Chrome) | Open the link, then tap **⋮ → Add to Home screen / Install app** |
| iPhone/iPad (Safari) | Open the link, then tap **Share → Add to Home Screen** |
| Windows/Mac (Chrome/Edge) | Click the **install icon** in the address bar |

## How to use
1. Add your players' names.
2. Choose **1 Court** or **2 Courts**.
3. Tap **Select Players** to get the games.
4. When a game ends, tap **Team A Won** or **Team B Won**.
5. In 2-court mode, tap **Next Game** on whichever court finishes first.

## Run it locally
Download the repo and open `index.html` in a browser. Offline/install support only works when the app is served over `https://` (for example, GitHub Pages) or `localhost`.
